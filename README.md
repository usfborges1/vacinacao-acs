# Vacinação ACS · USF José Borges 1

App do tablet dos Agentes Comunitários de Saúde para registrar vacinas.

## [⬇ Baixar o app (VacinacaoACS.apk)](https://github.com/usfborges1/vacinacao-acs/raw/main/VacinacaoACS.apk)

Versão atual: **1.1**

### Como instalar no tablet

1. Toque no link acima e baixe o arquivo.
2. Abra o arquivo baixado (aviso de download ou app **Arquivos → Downloads**).
3. Se aparecer **"Instalar apps desconhecidos"**, permita para o navegador e volte.
4. Toque em **Instalar**. Se o Play Protect avisar, toque em **Mais detalhes → Instalar mesmo assim**.

Para atualizar, baixe e instale de novo pelo mesmo link: os registros do tablet são mantidos.
